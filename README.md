# Microservices

This repository is a hands-on learning project that demonstrates the step-by-step evolution from a monolithic architecture to a complete microservices ecosystem. Each module represents a different stage in building scalable, resilient, and distributed systems.

## Concepts Covered

<ol>
    <li>Monolithic Application</li>
    <li>Splitting the Codebase</li>
    <li>Splitting the Database</li>
    <li>Centralized Configuration Management</li>
    <li>Load Balancing</li>
    <li>Service Discovery using Netflix Eureka</li>
    <li>Fault Tolerance with Circuit Breaker</li>
    <li>API Gateway</li>
    <li>Inter-service Communication</li>
    <li>Distributed Tracing</li>
    <li>Centralized Configuration using HashiCorp Consul</li>
    <li>Service Discovery using HashiCorp Consul</li>
    <li>Inter-service Communication using Spring HTTP Service Client</li>
    <li>Kafka Implementation</li>
</ol>
